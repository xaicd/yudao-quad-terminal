# Yudao Quad-Terminal `v1.2.0` Release Notes

> **发布日期**: 2026-11-16  
> **底座定位**: 四位一体企业级多端母版基座（Spring Boot 3 / JDK 17 + Vue 3 Admin + Uni-App 小程序/H5 + Expo React Native App）  
> **兼容契约版本**: `compat-manifest.json` (`templateVersion: "1.2.0"`, `blueprint.template.json` `schemaVersion: "2.1.0"`)

---

## 一、核心升级亮点 (Highlights)

### 1. `<500 Tokens` 声明式蓝图引擎与全栈同源交付 (`scripts/blueprint-engine.cjs`)
- **蓝图契约 v2.1 (`blueprint.template.json`)**：统一四端同源 `BASE_PATH` 变量插槽，自动派生 `/<slug>/{cockpit,admin,2c,admin-api,app-api,v3/api-docs}` 路由拓扑。
- **口语化蓝图自愈 (`pnpm blueprint:doctor`)**：自动修正领域蓝图中的字段类型、状态机、权限码与 `<=4` 字中文导航菜单规范。
- **一键全栈展开与真库验收 (`pnpm blueprint:deliver`)**：从单份 `<domain>.blueprint.json` 自动生成 16 份 Spec-Kit 规格资产、Java 6 层代码（DO / Mapper / Service / Admin+App Controller / VO）、Vue 3 管理端页面、TypeScript SDK、PostgreSQL/MySQL DDL 并联动真库 6 阶段 E2E。

### 2. 双支柱工程治理：`harness` 生命周期总控 × `speckit` CMMI 00–09 过程资产矩阵
- **支柱一 `harness` (`scripts/harness.cjs`)**：跨底座同名同参提供 `install | check | build | start | health | status | stop | e2e | deliver | pmo` 标准生命周期编排，以及 8 动词服务控制面 `deploy/service.sh`。
- **支柱二 `speckit` × CMMI 00–09 (`scripts/cmmi-00-meta.cjs` ~ `scripts/cmmi-09-operations.cjs`)**：完整覆盖元规范、PMO 立项沙箱孵化 (`pnpm pmo` / `pnpm project:init`)、需求分诊 (`pnpm agent:route`)、架构自愈、全栈实现、真 PG E2E、质量审计、不可变发布指纹、SRE 探活与历史规格防污染归档。

### 3. 零 Docker 本地真库闭环 (`lite` 档) 与净室派生引擎 (`ProjectReactor`)
- **Embedded PostgreSQL 18.4 + 嵌入式 Redis (`scripts/lib/ephemeral-pg.cjs`, `pnpm lite:verify`)**：免 Docker 秒级拉起真实 PostgreSQL 与 Redis，引导凭据由 CSPRNG 动态签发（`0600` 权限落盘，杜绝弱口令）。
- **连字符安全白标孵化 (`pnpm project:hatch` / `pnpm harness:hatch`)**：`ProjectReactor` 自动推导 `snakeSlug` / `pascalSlug`，彻底迁移 Java 包路径与 Maven `groupId`，清洗上游推广外链与前端 Home Mock 图表，生成零冲突 6 端口矩阵 (`.env.ports`) 与 `{ admin off }` Caddy 四平面网关配置。

### 4. 23 道出厂门禁、门禁反向控制、上游契约基线与全仓 `docs/` 统一归口
- **快速门禁与反向控制 (`pnpm check`, `pnpm compat:check`, `pnpm harness:controls`, `pnpm gates:23:static`)**：17 项 `fast` 门禁（`full` 档 20 项）+ 11 组兼容契约自检 + 10/10 项负向注入反向控制自证 + 99 个 `node:test` 自有脚本单测全绿 + 20 项 `harness:hatch` 派生金路径断言。
- **全仓文档统一归口 `docs/` (`docs/wiki/`, `docs/specs/`, `docs/07_release/releases/`, `docs/audit/`)**：彻底消除顶层并行文档目录与软链，与姊妹基座 `cooliebase-all` (`v1.5.0`，含 Admin + 2C + `clients/miniapp` + `clients/expo` 四端及 `oa/hrm/fms/pms` 等 18 插件) 及控制面 `coolie` (`v0.7.0`) 保持 100% 同构目录规范。
- **只读上游子模块契约基线 (`scripts/lib/upstream-contract-baseline.json`)**：对 `apps/backend`、`apps/admin`、`apps/miniapp` 三大只读上游子模块采用 `deploy/patches/*/*.patch` 声明式补丁收敛，并对上游固有 92 条未暴露孤儿端点建立精确基线对账（新增未授权孤儿或动词漂移立即拦截）。
- **自动化 Release 制品流水线 (`pnpm release:package`, `.github/workflows/release.yml`)**：支持一键构建离线纯净四端骨架包 (`yudao-quad-terminal-v1.2.0-skeleton.tar.gz`)、`compat-manifest.json`、`blueprint.template.json` 与 `SHA256SUMS.txt` 并在推送 `v*` 标签时自动发布 GitHub Releases。
